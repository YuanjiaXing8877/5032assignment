# GreenLink Melbourne - Iteration 1

This Vue application contains a login page and a personal volunteer dashboard.

## Run locally

```bash
npm install
npm run dev
```

## Included in this iteration

- Vue Router navigation between login and profile views
- Required, email format, password length and password content validation
- Show and hide password interaction
- Editable personal information with field-level validation
- Personal information and activity history tables
- Summary values computed from the activity data
- Responsive layouts for phone, tablet, desktop and wide screens

Authentication and database storage are reserved for a later iteration.
